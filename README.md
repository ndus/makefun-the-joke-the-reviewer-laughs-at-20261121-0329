A dependency-free Node program writes one joke about working beside an AI coding agent. It writes the same one-line joke to `/output`, or to the directory set by `MAKEFUN_OUTPUT_DIR`.

## Run it

```sh
node main.ts
```

It writes `entry.txt` (the joke) to `/output`, or to `$MAKEFUN_OUTPUT_DIR` when that is set.
